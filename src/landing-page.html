Workflow

From install to insight in minutes.

No external agents, no complex cloud setup. Just one package in your repository.

STEP 01

Install Package

Save as a standard dependency in your existing Node.js application.

npm install server-devtools
STEP 02

Mount Runtime

Add ServerDevTools to your Express or NestJS app with two lines of code.

await devtools.start(app);
STEP 03

Inspect Live

Open the local dashboard and inspect requests in real-time as they process.

http://localhost:3000/_devtools

Embedded Architecture

Runs inside your application.

ServerDevTools is an embedded module inside your backend runtime — not an external SaaS agent or separate database.

check_circle Zero cloud telemetry egress or external data ingestion
check_circle Auto-disabled in production via environment flags
check_circle Zero config async instrumentation using AsyncLocalStorage
app.ts 
import express from "express";
import { ServerDevTools } from "server-devtools";

const app = express();
const devtools = new ServerDevTools({
  path: "/_devtools",
  enabled: process.env.NODE_ENV !== "production",
});

await devtools.start(app);

// Your normal routes
app.get("/users/:id", async (req, res) => {
  const user = await db.users.findById(req.params.id);
  res.json(user);
});

app.listen(3000);
